# Portfolio — María Arami Vera Vargas

Portfolio personal (Contadora Pública) hecho con React + TypeScript + Vite.

- Sitio: https://josuever327.github.io/ara-vera-portfolio/
- Contenido editable en `src/data.ts`.
- Foto y CV en `public/`.
- Se publica automáticamente en GitHub Pages al hacer push a `main` (`.github/workflows/deploy.yml`).

```bash
npm install
npm run dev
```
